1. 이 앱은 뭐 하는 앱인가요?

키를 정하면 쓸 수 있는 코드가 자동으로 나오고, 탭하면 소리가 나고, 진행이 쌓이는 앱.

악보를 읽을 줄 몰라도, 이론을 몰라도 됩니다.

"C 장조로 팝 느낌 곡을 만들고 싶다"
→ 키 C, 장조 선택 → 코드 7개가 뜸 → 탭탭탭 → 진행 완성

  • 기타·피아노 연주자가 새 곡 아이디어를 찾을 때
  • 작곡 중 "다음에 어떤 코드가 어울리지?" 할 때
  • 코드 이론을 배우면서 직접 듣고 확인하고 싶을 때

2. 처음 5분 — 빠른 시작

Step 1. 키와 모드 선택

홈 화면에서 키(예: C), 모드(장조/단조), 레벨(입문)을 고르고 탐색 시작 버튼.

Step 2. 코드 탭에서 코드 탭하기

가운데에 7개 코드가 보입니다. 하나씩 탭해보세요. 탭할 때마다 소리가 납니다.

 I      II     III    IV     V      VI     VII
 C      Dm     Em     F      G      Am     B°

마음에 드는 코드를 탭하면 아래 진행 히스토리에 쌓입니다.

Step 3. 진행 만들기

코드를 4개 골라보세요. 예를 들어 C → Am → F → G 순서로 탭.

[마디 1]
C    Am    F    G

Step 4. 재생

▶ 재생 버튼을 눌러 진행을 들어보세요. BPM 버튼으로 빠르기 조절 가능.

Step 5. 변형해보기

C를 탭한 상태에서 아래 변형 코드 버튼 중 Cmaj7을 탭해보세요. 느낌이 달라집니다.

이게 기본 흐름입니다. 나머지 기능(GPS, 기법 제안, 분석 등)은 이 흐름 위에 얹히는 것들입니다.

3. 홈 화면

앱 실행 시 첫 화면. 여기서 정한 설정이 앱 전체에 적용됩니다.

키 (Key)

C, C#, D, D#, E, F, F#, G, G#, A, A#, B 중 하나.

모르겠으면 C로 시작하세요. 나중에 전조 기능으로 언제든 바꿀 수 있습니다.

장조 / 단조

느낌 예시
장조 밝고 기쁜, 안정적 팝, 록, 밝은 발라드
단조 어둡고 감성적 슬픈 발라드, 드라마틱한 곡

레벨

코드의 복잡도를 결정합니다. 처음엔 입문 또는 중급 추천.

레벨 I·IV도 V도 II·III·VI도 VII도 특징
입문 C G Am, Dm, Em B° 기본 3화음. 기타 오픈 코드로 다 잡힘
중급 Cmaj7 G7 Am7, Dm7, Em7 Bø7 7th 추가. 팝·R&B 느낌
재즈 🔒 Cmaj9 G13 Am9, Dm9, Em9 Bø7 텐션 코드. 재즈·네오소울

레벨은 네비게이터 화면의 분석·스케일 탭에서도 언제든 바꿀 수 있습니다.

4. 코드 탭 완전 정복

네비게이터 화면의 메인 탭. 화면을 위에서 아래로 훑으면서 설명합니다.

상단 바 — 키 표시 및 전조

← 키    C 장조    키 →         × 전조 해제    🎵 전조
  • ← 키 / 키 →: 키를 반음씩 올리거나 내립니다
  • 🎵 전조: 키를 한 번에 선택하는 모달 열기
  • × 전조 해제: 원래 키로 복귀
  • 전조 중에는 배지에 현재 키가 색으로 강조됩니다

전조가 유용한 상황: C로 만든 진행을 기타리스트는 G로, 보컬 음역에 맞게 조정할 때

내 진행 (히스토리)

[마디 1]                     [마디 2]
Cmaj9  Am9  Fmaj9  G13   |   Cmaj9  Em9  ...
                              ↑ 편집 중 (강조)

기본 동작:
- 코드 탭 → 현재 마디 끝에 추가
- 4코드 채우면 자동으로 다음 마디 시작
- 코드 칩 탭: 그 슬롯에 커서 이동 → 다음에 탭하는 코드로 교체됨
- 마디 헤더 ✕: 그 마디 전체 삭제
- 마지막 마디 ＋: 새 빈 마디 추가 (마디는 무제한 무료)
- 초기화: 진행 전체 삭제

변형 코드

코드를 선택하면 바로 아래에 변형 버튼들이 가로로 나열됩니다.

중급 레벨, C 선택 시:

C(기본)  Cmaj7  C7  Cadd9  Csus4  Csus2  C6

재즈 레벨, C 선택 시:

C(기본)  Cmaj7  Cmaj9  C7  C9  C13  Cadd9  Csus4

탭하면 즉시 그 변형으로 바뀌고 소리가 납니다.

변형 코드 뜻:
| 변형 | 핵심 | 느낌 |
|------|------|------|
| (기본) | 3화음 | 가장 단순하고 깨끗 |
| maj7 | 장7도 추가 | 부드럽고 몽환적 (로맨틱) |
| 7 | 단7도 추가 | 긴장감, 블루지 |
| 9 | 7+9도 | 풍성하고 모던 |
| 13 | 7+9+13도 | 가장 풍성, 재즈적 |
| m7 | 단3화음+단7도 | 재즈·R&B 기본 |
| m9 | m7+9도 | 네오소울 느낌 |
| add9 | 9도만 추가 (7 없이) | 청명하고 열린 느낌 |
| sus4 | 3음을 4음으로 교체 | 공중에 뜬 느낌, 미해결 |
| sus2 | 3음을 2음으로 교체 | 열리고 투명한 느낌 |
| ø7 | 반감화음 | 긴장, 전환점 |

GPS 루트

"지금 코드에서 어디로 가면 좋을까?" 를 3가지 루트 카드로 보여줍니다.

┌─────────────────────────────┐  ┌──────────────────────────────┐
│ 팝  · 안정감                │  │ 재즈 · 진행감                │
│ Cmaj9→Am9→Fmaj9→G13        │  │ Cmaj9→Em9→Dm9→G13           │
│ [팁: I-VI-IV-V 팝 황금 진행]│  │ [팁: I-III-II-V 재즈 순환]  │
│              → 이 루트로    │  │              → 이 루트로    │
└─────────────────────────────┘  └──────────────────────────────┘
  • 각 코드 위에 역할 라벨 (안정/움직임/따뜻함/색채/해소)
  • → 이 루트로 버튼: 카드의 코드들을 진행에 한번에 추가
  • 우측 상단 규칙 또는 AI 배지: 현재 사용 중인 방식
규칙 기반 AI 기반 🔒
조건 항상 (무료) 프리미엄 + API 키
속도 즉시 약 1초
품질 장르 패턴 기반 진행 맥락·레벨·장르 종합

장르 바꾸기: 분석·스케일 탭 → 장르 버튼 선택. GPS 루트 스타일이 바뀝니다.

기법 제안

현재 코드에서 쓸 수 있는 코드 이론 기법을 2~5가지 자동으로 제안합니다.

각 기법 그룹 상단에:
- ▶ 재생: 기법 시퀀스를 BPM에 맞춰 순서대로 미리 들어보기
- → 사용: 현재 코드 자리를 이 기법 시퀀스로 교체

개별 코드 칩을 탭하면 그 코드 하나만 진행에 추가됩니다.

① 대리코드

구성음이 많이 겹치는 코드로 교체해 색다른 느낌.

원래 도수 대리코드 이유
I (Cmaj) VI (Am) C·E 공유
VI (Am) I (Cmaj) 반대 방향 대리
V (G7) 삼전음 (Db7) G7 ↔ Db7는 서로 반음음정 대리
V (G7) II-V (Dm7-G7) V를 앞에서 준비
IV (Fmaj) II (Dm) F·A 공유

② 클리셰

같은 루트음에서 한 음씩 반음 내려가며 색이 바뀌는 기법. 장조 코드에서만 나타납니다.

C → Cm → Cm7
(3음: E → E♭ → E♭, 7음 추가)

팝·발라드에서 자주 들리는 "눈물 흘러내리는" 느낌.

③ 베이스 하강

루트음을 유지하면서 베이스만 반음씩 내려가는 기법. I도에서만 나타납니다.

C → C/B → Am/A → Am/G
   베이스: C → B → A → G

파헬벨 캐논이 이 원리. 베이스가 계단처럼 내려가며 자연스러운 흐름.

④ 페달 포인트

특정 음을 베이스에 고정하고 그 위 화음만 바꾸는 기법.

현재 코드가 C일 때:
F/C → G/C → Am/C
(베이스 C 고정, 위 화음만 이동)

전자음악·앰비언트에서 드론처럼 울리는 베이스음 위에 화음이 변하는 그 느낌.

⑤ 코드 쪼개기 (경과코드)

다음 코드로 가기 직전에 그 코드의 도미넌트7을 삽입하는 기법.

C → G7 → Am
     ↑
  Am의 경과코드 (E7을 넣는 경우도 있음)

목적지 코드가 더 강하게 들리게 만드는 재즈 필수 기법.

운지 다이어그램

코드 선택 시 화면 하단에 기타·피아노 운지가 표시됩니다.

탭 전환:

[기타]  [피아노]  [스트럼]  [아르페지오]

기타 운지:
- 포지션 버튼 (예: 오픈 / A형 3프렛 / E형 8프렛)으로 다른 포지션 전환 가능
- 운지 데이터 없음 = 해당 코드 변형에 대한 데이터 미포함 (재즈 확장 코드 일부)

피아노 운지:
- 루트 포지션 / 1전위 / 2전위 버튼으로 전환
- 색으로 구성음 표시

하단 영역 — 추천 진행·곡 매칭·장르 감지

추천 진행:

I-V-VI-IV   I-IV-V-I   II-V-I

팝/재즈에서 자주 쓰는 3가지 정형 패턴. 진행에 있는 코드는 강조 표시.

곡 매칭:
진행이 4코드 이상 되면 비슷한 패턴의 유명 곡 이름이 표시됩니다.

장르 감지:
쌓인 진행의 도수 패턴을 분석해 "팝 스타일 감지됨" 같은 정보를 표시.

5. 분석·스케일 탭

하단 분석·스케일 탭. 내부에 분석 / 스케일 서브탭.

분석 서브탭

코드 탭에서 만든 진행을 분석하고 개선안을 제안합니다.

화면 순서:

1) 코드 진행 입력창
코드 탭의 진행이 자동으로 들어옵니다. 직접 수정하거나 새로 입력도 가능합니다.

Cmaj9 Am9 Fmaj9 G13

2) 장르 선택
팝 / 록 / 재즈 / R&B / 발라드 / 보사노바

3) 레벨 선택
입문 / 중급 / 재즈 🔒

4) 규칙 기반 분석 버튼 (무료)
API 없이 즉시. 다음 3가지 버전 생성:
- 7th 버전: 모든 코드에 7th 추가 (Cmaj9→Cmaj9maj7)
- 대리코드 버전: I↔VI, V↔II 대리 적용
- 재즈 (트리톤 대리): dom7 코드를 반음 위 dom7으로 교체

5) AI 분석 버튼 🔒 (프리미엄 + API 키 필요)
Claude AI가 맥락을 이해하고 분석합니다.
- 원본 분석: "이 진행이 왜 효과적인지" 2문장 설명
- 장르 버전: 선택 장르 스타일로 코드 변환
- 레벨 버전: 선택 레벨 복잡도로 조정
- 대리코드 버전: 대리코드 활용 버전

각 결과 카드에 ▶ 재생 버튼으로 미리 들어볼 수 있습니다.

API 키 설정:
1. console.anthropic.com 접속 후 API 키 발급
2. 분석 탭 상단 입력창에 붙여넣기 → 저장
3. 이후 GPS AI 루트 + AI 분석 모두 활성화됨

스케일 서브탭

현재 진행에 어울리는 스케일을 찾아주고, 선택한 스케일의 지판/건반을 시각화합니다.

1) 내 진행에 맞는 스케일 (자동 추천)
코드가 2개 이상 쌓이면 진행의 구성음을 분석해 잘 맞는 스케일 최대 4개 표시.

C 장조 (Ionian)   98%   ← 1위 (파란 강조)
A 도리안          82%
G 믹솔리디안      79%
...

탭하면 그 키와 스케일이 자동으로 선택되어 아래에 즉시 표시됩니다.

2) 스케일 모드 직접 선택 (10개)

모드 특징 잘 맞는 장르
Ionian (장조) 밝고 안정적 팝, 록
Dorian 마이너지만 밝은 느낌 재즈, 펑크, 네오소울
Phrygian 어둡고 이국적 플라멩코, 메탈
Lydian 밝고 몽환적 (#4도) 영화음악, 드림팝
Mixolydian 장조지만 b7 블루스, 록
Aeolian (단조) 어둡고 감성적 발라드, 클래식
Harmonic Minor 어둡고 극적 클래식, 플라멩코
Pentatonic Major 단순하고 강렬 팝, 록 솔로
Pentatonic Minor 블루지, 감성적 블루스, 록 솔로
Blues Pentatonic Minor + b5 블루스

3) 구성음 표시
선택한 키+스케일의 음을 칩으로 표시. 루트음은 보라색으로 강조.

4) 기타 지판 / 피아노 건반 시각화
스케일 음 위치를 악기에 직접 표시. 솔로·즉흥 연주 참고용.

5) 이 스케일의 코드
7음 스케일이면 7개의 다이아토닉 코드 표시. 탭하면 소리 재생.
전체 진행 추가 버튼으로 7개 코드를 한번에 진행에 추가.

6. 실전 시나리오 4가지

시나리오 A: 팝 발라드 만들기

  1. 홈: C 장조, 중급 선택
  2. 코드 탭 → Cmaj7 탭 (I)
  3. 하단 GPS 루트에서 "발라드" 느낌 카드 → → 이 루트로 버튼
  4. 진행에 Cmaj7 → Am7 → Fmaj7 → G7 자동 추가
  5. 각 코드 탭해서 변형 조정 (예: G7 → Gsus4 → G7 로 클리셰 효과)
  6. BPM 70 설정 후 ▶ 재생

시나리오 B: "다음 코드 뭐가 어울리지?" 해결하기

  1. 코드를 몇 개 탭해서 진행 만들기
  2. 마지막으로 고른 코드를 탭 (선택 상태로)
  3. GPS 루트 카드 3개 확인 → 분위기 맞는 카드의 코드 개별로 탭해보기
  4. 또는 다음 추천 › 텍스트 아래에 표시된 코드들 탭해보기
  5. ↑ 화살표 있는 코드도 유력 후보

시나리오 C: 커버곡 코드를 앱에서 확인하기

  1. 분석·스케일 탭 → 분석 서브탭 진입
  2. 진행 입력창에 직접 코드 입력: Am F C G
  3. 규칙 기반 분석 버튼 → 7th 버전, 대리코드 버전 등 제안 확인
  4. 마음에 드는 버전 카드의 ▶ 재생 으로 미리 듣기
  5. 코드 탭으로 돌아가 그 코드들 직접 탭해서 구현

시나리오 D: 솔로·즉흥 연주를 위한 스케일 찾기

  1. 코드 탭에서 진행 4코드 이상 만들기
  2. 분석·스케일 탭 → 스케일 서브탭 진입
  3. 상단 추천 스케일 중 1위 탭 → 키와 스케일 자동 적용
  4. 기타 지판 또는 피아노 건반 탭에서 스케일 음 위치 확인
  5. 코드 탭으로 돌아가 ▶ 재생하면서 스케일 연습

7. 자주 묻는 질문 (FAQ)

Q. 운지 데이터 없음이 뜨는 코드가 있어요.
일부 재즈 확장 코드(maj9, m11 등)는 운지 데이터가 없습니다. 대신 CAGED 시스템 기반 근사 운지가 자동 계산되지만, 커버되지 않는 경우 "운지 데이터 없음" 표시가 납니다. 이때는 기본 변형(예: maj7)을 선택하거나 직접 운지를 찾아보세요.

Q. GPS 루트 카드가 항상 비슷하게 나와요.
장르 설정을 바꿔보세요. 분석·스케일 탭 → 분석 서브탭 → 장르 선택. 팝·재즈·발라드·보사노바별로 다른 패턴이 나옵니다.

Q. 편집 커서가 어떻게 작동하나요?
진행 히스토리에서 이미 있는 코드 칩을 탭하면 그 슬롯에 편집 커서가 생깁니다. 이후 다이아토닉 코드 버튼을 탭하면 새로 추가되는 게 아니라 그 자리가 교체됩니다. 새로 추가 모드로 돌아가려면 빈 공간을 탭하거나 마지막 마디 뒤 ＋ 버튼을 누르세요.

Q. 전조와 키 변경의 차이가 뭔가요?
- 홈 화면 키 설정: 처음부터 그 키로 시작
- 전조 (네비게이터 상단 🎵 전조): 현재 진행은 유지하되 다이아토닉 코드·GPS 루트·기법 제안의 기준 키만 임시 변경. "전조 해제"하면 원래 키로 돌아옴

Q. 재즈 레벨이 잠겨 있어요.
재즈 레벨은 프리미엄 기능입니다. 분석 탭에서 재즈 버튼을 탭하면 구독 안내 화면이 나타납니다.

Q. API 키 없이도 AI 기능을 쓸 수 있나요?
아니요. AI GPS 루트와 AI 분석은 Anthropic API 키가 필요합니다. console.anthropic.com에서 발급 후 분석 탭 상단에 입력하세요. 키 없이는 규칙 기반(무료) 기능만 사용됩니다.

Q. 저장한 진행이 사라졌어요.
저장은 기기 로컬에 저장됩니다. 앱 삭제 시 함께 삭제됩니다.

Q. 3화음(기본)과 7화음의 차이를 모르겠어요.
3화음은 루트·3도·5도 3개 음, 7화음은 거기에 7도 음이 하나 더 추가됩니다. 소리를 직접 들어보는 게 가장 빠릅니다. 같은 코드를 탭한 상태에서 변형 버튼 C(기본) → Cmaj7 → C7 순서로 눌러보세요.

8. 음악 이론 미니 사전

앱을 쓰다 보면 자주 만나는 용어들.

다이아토닉 코드

특정 키의 음계(7개 음) 각각을 루트로 하는 7개 코드.
이 7개 안에서 코드를 고르면 거의 다 어울립니다.

예: C 장조 = C D E F G A B
- C를 루트 → Cmaj (I)
- D를 루트 → Dm (II)
- G를 루트 → G (V)

도수 (I~VII)

코드가 음계의 몇 번째 음을 루트로 하는지. 로마 숫자로 표기.
- I도: 으뜸화음. 가장 안정적. 곡의 시작·끝에 많이 쓰임
- V도: 딸림화음. 긴장감 최고. I도로 해결하려는 힘이 강함
- IV도: 버금딸림. 안정적이지만 움직임이 있음
- VI도: 나란한조 으뜸. I도 대신 써도 자연스러움 (대리코드)

도미넌트

V도 코드. C 장조에서는 G 또는 G7.
긴장감을 만들어 I도(해결)로 이끄는 코드.

대리코드 (Substitution)

구성음이 많이 겹쳐서 서로 대신 쓸 수 있는 코드.
- Cmaj (C·E·G) ↔ Am (A·C·E): C·E 공유 → 서로 대리 가능

전위 (피아노 운지)

  • 루트 포지션: 루트음이 가장 아래 (C-E-G)
  • 1전위: 3음이 가장 아래 (E-G-C)
  • 2전위: 5음이 가장 아래 (G-C-E)

텐션 코드 (9th, 11th, 13th)

기본 4화음(7th)에 음을 더 추가한 코드.
9th = 2도 위 음, 11th = 4도 위 음, 13th = 6도 위 음.
음이 쌓일수록 풍성하고 재즈스러워집니다.

삼전음 (Tritone Substitution)

도미넌트7 코드를 정확히 반음계의 6음 위(반 옥타브) 코드로 교체하는 기법.
G7 ↔ Db7 (서로의 3음·7음이 뒤바뀜)
재즈에서 V도를 더 색다르게 표현할 때 사용.
